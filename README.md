# Ario – نسخه وب

نسخه‌ی وب برنامه‌ی Ario (برنامه‌ریز روزانه). این پوشه یک سایت استاتیک کامل است؛ نیازی به بیلد ندارد.

## انتشار روی GitHub Pages
1. در GitHub یک ریپازیتوری جدید بسازید (مثلاً `ario`).
2. همه‌ی فایل‌های همین پوشه (نه خود پوشه) را در ریشه‌ی ریپو آپلود کنید (`Add file ← Upload files`). فایل `.nojekyll` هم باید باشد.
3. `Settings ← Pages ← Build and deployment`: گزینه‌ی `Deploy from a branch`، شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب و Save کنید.
4. بعد از ۱ تا ۲ دقیقه سایت در `https://USERNAME.github.io/REPO/` باز می‌شود.

## نکته‌ها
- داده‌ها در مرورگر هر کاربر ذخیره می‌شوند (localStorage)؛ قابلیت‌های ابری (چت، همگام‌سازی) از Supabase استفاده می‌کنند.
- اگر ورود با گوگل یا لینک ایمیلی دارید، آدرس سایت را در Supabase ← Authentication ← URL Configuration به Redirect URLs اضافه کنید.
- قابلیت‌های مخصوص اندروید (ویجت، قفل برنامه، اعلان بومی، Focus Guard) در وب کار نمی‌کنند.
- اسکن عکس جدول (OCR) در وب فایل‌های لازم را از CDN می‌گیرد، پس به اینترنت نیاز دارد.
- برنامه PWA است: در موبایل از منوی مرورگر «Add to Home screen» بزنید تا مثل برنامه نصب شود و بعد از اولین باز کردن آفلاین هم کار کند.
- هنگام به‌روزرسانی، در `sw.js` مقدار `V` را عوض کنید تا کش قدیمی پاک شود.
